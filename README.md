# EnhanceM

一个增强怪物行为的 Minecraft 模组——让怪物更聪明、更强大、更具挑战性。

## 功能特性

- **更智能的小白AI** — 骷髅等弓箭手在玩家靠近时会逃跑，防止被近战秒杀，并且骷髅会追逐超出弓箭射程的玩家，主动拉近距离进行攻击。
- **会吐丝的蜘蛛** -蜘蛛在攻击玩家时，25%的概率会在玩家脚下生成一格蜘蛛网
- **更高的经验获取效率** -作为补偿，玩家的经验获取效率翻2.5倍
- 更多功能即将推出。

## 更新计划

- 僵尸的速度加快，比玩家的行走速度快，但比玩家奔跑速度慢
- 每个僵尸手中都随机生成工具，铁器概率最高，下界合金概率最低。僵尸在走向玩家时受阻会挖掘阻拦方块，挖掘效率受手上工具影响（例如镐子挖石头快，金镐子比铁镐子快）。如果手上生成的工具是剑，那么有概率附魔火焰附加或者锋利。
- 有概率生成左手持盾的僵尸，在靠近玩家到攻击范围后，僵尸会在没攻击的间隔将盾举起用于格挡，格挡时像玩家一样有潜行减速效果。玩家也可以正常用斧子破盾
