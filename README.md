# EnhanceM

一个增强怪物行为的 Minecraft 模组——让怪物更聪明、更强大、更具挑战性。

## 功能特性

- **更智能的小白AI** — 骷髅等弓箭手在玩家靠近时会逃跑，防止被近战秒杀，并且骷髅会追逐超出弓箭射程的玩家，主动拉近距离进行攻击。
- **会吐丝的蜘蛛** -蜘蛛在攻击玩家时，25%的概率会在玩家脚下生成一格蜘蛛网
- **更高的经验获取效率** -作为补偿，玩家的经验获取效率翻2.5倍
- **全面强化的僵尸** -僵尸速度改为0.35，比玩家的行走速度快，但比玩家奔跑速度慢
- **随机工具生成的僵尸** -每个僵尸手中都随机生成工具，铁器概率50%，黄金30%，钻石15%，下界合金5%。如果手上生成的是剑，有25%概率附魔火焰附加2或锋利3
- **怪物的攻击距离提高**
- 更多功能即将推出。
