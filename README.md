# EnhanceM

一个增强怪物行为的 Minecraft Fabric 模组——让怪物更聪明、更强大、更具挑战性。目标游戏版本为 26.3。

## 版本信息

- 模组版本：1.3.1
- Minecraft：26.3
- Fabric Loader：0.19.5
- Fabric API：0.161.0+26.3

## 功能特性

- **更智能的小白AI** - 骷髅等弓箭手在玩家靠近时会逃跑，防止被近战秒杀，并且骷髅会追逐超出弓箭射程的玩家，主动拉近距离进行攻击。
- **会吐丝的蜘蛛** - 蜘蛛在攻击玩家时，50%的概率会在玩家脚下生成一格蜘蛛网
- **更高的经验获取效率** - 作为补偿，玩家的经验获取效率翻3倍
- **玩家死亡掉落物不再超时消失** - 仅玩家死亡时掉落的物品免于超时消失，仍可能被火、岩浆、爆炸等破坏。
- **全面强化的僵尸** - 普通僵尸（含尸壳、僵尸村民）平时保持原版速度，近战追击时通过原版导航 AI 加速，追击速度与原版卫道士一致（0.35）；持矛时仅在冲刺阶段加速，盾牌僵尸保持原速
- **随机工具生成的僵尸** - 僵尸主手有90%概率生成随机工具，剩余10%初始空手，是否携带物品由原版生成逻辑及概率决定。生成工具时，铜器概率25%，铁器概率25%，黄金30%，钻石15%，下界合金5%。每档材质内剑、镐、斧、锹、锄各占18%，长矛占10%（铜矛/铁矛/金矛/钻石矛/下界合金矛随档位生成）。如果手上生成的是剑，有25%概率附魔火焰附加2或锋利3；如果手上生成的是长矛，有25%概率附魔击退1、5%概率附魔击退2、70%概率不添加附魔，持矛僵尸会使用原版长矛冲锋AI（蓄力突刺、拉开身位走位）
- **剑圣僵尸（持剑僵尸）** - 手持剑且副手无盾的僵尸会施展专属的双段连招：每次出手都会连续挥砍两刀，两段动作无缝衔接，造成两段伤害。无攻击冷却，一轮连招结束后立刻开始新一轮，对靠近的玩家形成持续压制
- **剑盾僵尸** - 僵尸生成时有 25% 概率在副手装备盾牌，移速调整为 0.23。进入近战后会在攻击间隙举盾防御；主手持剑时，每次攻击有 50% 概率保持格挡并发动专属前刺动画，在盾牌保护下完成攻击
- **强化的猪灵武装** - 持弩猪灵射出的箭命中后会造成强击退并附带1秒迟缓，持剑猪灵的剑固定附魔火焰附加2，持长矛猪灵的长矛固定附魔击退3
- **强化的猪灵蛮兵** -猪灵蛮兵近战命中后会对玩家附加1秒迟缓，并强制玩家趴下0.5秒
- **更聪明的僵尸猪灵** - 追击玩家时会停在近战攻击范围边缘，不再持续贴脸；每次命中后都会迅速后撤，等待下一轮攻击再重新压上来
- **强化的僵尸猪灵武装** - 僵尸猪灵持剑时固定附魔火焰附加2，持长矛时固定附魔击退3
- **怪物近战攻击范围微调** - 怪物（Monster 类及其子类）的原版近战攻击碰撞箱在水平方向、上方和下方各额外扩展 0.5 格（每侧增加 0.5 格）。攻击冷却和视线检查仍由原版 AI 处理。
- **双形态苦力怕** - 50%概率生成普通移速苦力怕，另外50%为快速苦力怕，追击速度与原版卫道士一致（0.35），闲逛时保持原版速度；普通移速苦力怕爆炸后会对爆炸半径内的玩家施加5秒失明、反胃和迟缓II
- **强化的溺尸** - 溺尸近战命中会额外减少玩家5格氧气，连续命中可导致玩家更快窒息；同时溺尸游泳速度提升。溺尸站在地面且不在水中时持续获得缓慢 IV，移动速度降低 60%，保留原速度的 40%（无其他效果干扰时）；效果持续 10 个游戏刻并在即将结束时刷新，因此离开地面或进入水中后仍可能残留约 0.5 秒（正常 20 TPS 下）。
- **马移速变为1.2倍**
- **神佑附魔** - 可附魔在头盔、胸甲、护腿、靴子上，无法通过附魔台获得，只能通过铁砧 + 附魔书使用。附魔书以 50% 概率生成于猪灵堡垒宝藏室宝箱，以 10% 概率生成于猪灵堡垒另外三类宝箱（普通房间、桥梁、猪灵马厩）和地狱堡垒宝箱。穿上后可触发类似不死图腾的保命效果，激活后对应部位的装备会保留到 5% 耐久；低于或等于 5% 时则直接破碎并且不激活任何效果，玩家正常死亡。
- **重生宝珠** - 重生宝珠可以使用使用后播放5秒动画后可以传送回家，中途受到攻击则传送失效，无论传送是否成功，宝珠用一个少一个，这是合成配方布局（3×3）：
  紫水晶簇  罗盘    紫水晶簇
  末影珍珠  诡异菌柄  紫水晶簇
  紫水晶簇  钻石    紫水晶簇
- **疾风靴** - 属性和皮革靴子一样，穿上后在陆地疾跑时移速变成1.6倍，奔跑时饱食度消耗变成两倍。此靴子可以正常附魔其它靴子附魔效果。以 50% 概率生成于猪灵堡垒宝藏室宝箱，以 10% 概率生成于猪灵堡垒另外三类宝箱（普通房间、桥梁、猪灵马厩）和地狱堡垒宝箱。
- **末影龙-豪华boss战** - 末影龙血量变为3倍；原版龙息弹命中后有 50% 概率转化为“末影之息”，范围按中心点球形半径判定，命中的玩家会被随机传送，同时激活附近所有末影人的仇恨
- **末影龙吐弹加速** - 末影龙对玩家吐龙息弹的实际发射频率更高
- **末影小兵** - 末影龙每下降20%血量就会召唤3个末影小兵攻击玩家，小兵手持下界合金斧。小兵受到攻击后会像末影人一样传送走。并且仇恨值这样计算：上一个在5秒内攻击自己的玩家，不满足则指向距离最近的玩家 来计算。并且像末影人一样不会被远程武器击中，在远程武器击中前会传送。
