# EnhanceM

一个增强怪物行为的 Minecraft Fabric 模组——让怪物更聪明、更强大、更具挑战性。目标游戏版本为26.1.2.

## 版本信息

- Minecraft：26.1.2
- Fabric Loader：0.19.2
- Fabric API：0.147.0+26.1.2
- Mod 版本：1.0.0

## 功能特性

- **更智能的小白AI** — 骷髅等弓箭手在玩家靠近时会逃跑，防止被近战秒杀，并且骷髅会追逐超出弓箭射程的玩家，主动拉近距离进行攻击。
- **会吐丝的蜘蛛** -蜘蛛在攻击玩家时，25%的概率会在玩家脚下生成一格蜘蛛网
- **更高的经验获取效率** -作为补偿，玩家的经验获取效率翻3倍
- **玩家死亡掉落物永久保留** -只有玩家死亡后掉落出来的物品不再自然消失，没有时间限制，怪物掉落仍保持原版行为
- **全面强化的僵尸** -僵尸速度改为0.35，比玩家的行走速度快，但比玩家奔跑速度慢
- **随机工具生成的僵尸** -每个僵尸手中都随机生成工具，铜器概率25%，铁器概率25%，黄金30%，钻石15%，下界合金5%。如果手上生成的是剑，有25%概率附魔火焰附加2或锋利3
- **强化的猪灵武装** -持弩猪灵射出的箭命中后会造成强击退并附带1秒迟缓，持剑猪灵的剑固定附魔火焰附加2，持长矛猪灵的长矛固定附魔击退3
- **强化的猪灵蛮兵** -猪灵蛮兵近战命中后会对玩家附加1秒迟缓，并强制玩家趴下0.5秒
- **更聪明的僵尸猪灵** -追击玩家时会停在近战攻击范围边缘，不再持续贴脸；每次命中后都会迅速后撤，等待下一轮攻击再重新压上来
- **强化的僵尸猪灵武装** -僵尸猪灵持剑时固定附魔火焰附加2，持长矛时固定附魔击退3
- **怪物的攻击距离提高** -水平和垂直攻击距离都提高了
- 更多功能即将推出。

## 更新计划

1. 末影人死后产生黑洞，吸引周围的物品和玩家，吸引效果就像爆炸冲击波效果的反向
2. 烈焰人攻击间隔大大缩短到只有1秒
3. 马移速翻倍，撞到生物有击飞和扣血效果
